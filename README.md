# Zen Notes 0.5.1 alpha

Оновлена копія мода. Оригінальні файли не змінено; у профіль браузера ця збірка автоматично не встановлювалася.

## Встановлення

Замініть ZenNotes.uc.js, ZenNotes.css та theme.json у встановленій локальній копії мода Sine файлами з цього каталогу, потім повністю перезапустіть Zen. Не запускайте дві версії одночасно.

## Виправлення 0.5.1

- Create Note розміщується безпосередньо під New Folder / Create Folder.
- Вставлені HTTP(S) URL одразу відображаються посиланнями; звичайний клік відкриває їх без клавіш-модифікаторів.
- Add to Note читає selectionInfo.fullText після ініціалізації браузерного контекстного меню.
- Іконка нотатки відновлюється після перезапису favicon при вивантаженні/відновленні pinned tab; CSS також фіксує потрібний glyph.
- Додаткові автоматизовані перевірки: URL, URL у code, звичайний клік, позиція Create Note, меню вибору двох нотаток.

## Зміни

- Автозбереження читає Markdown без перебудови активного contenteditable та скидання курсора.
- Enter продовжує булети, нумерацію, задачі й цитати. Порожній пункт або цитата завершує список/цитату. Виділений текст замінюється при Enter.
- Курсор установлюється синхронно: відкладені animation frames більше не переносять його після наступного введення.
- Markdown-заголовки, жирний/курсив, закреслення, highlight, inline/fenced code, задачі, цитати, wikilinks, посилання, прості pipe-таблиці й callouts.
- Звичайний клік відкриває HTTP(S)-посилання в новій вкладці або переходить до існуючої нотатки через [[точна назва]] / [[назва|підпис]]. Ctrl/Cmd+K обгортає виділення шаблоном посилання.
- Правий клік у нотатці: Copy, Cut, Paste, Select All (поточний рядок/заголовок).
- Create Note у контекстних меню вкладок/панелі та попередньому меню «+».
- Виділення на сайті → Add to Note → назва нотатки або Create Note. Текст додається в кінець файлу.
- Кожна нотатка має окремий Boost-профіль <note-id>.zen-notes.local. Старий спільний Boost залишається у сховищі Zen, але більше не застосовується до нотаток.
- Спостерігач за назвою вкладки відновлює назву нотатки після зміни на New Tab.
- Повне закриття останньої вкладки нотатки видаляє її .md та запис index.json. Вивантаження/скидання закріпленої вкладки зі збереженням самої вкладки не видаляє файл. Видалення незворотне для вмісту нотатки; Undo Close Tab файл не відновить.
- Послідовна черга записів запобігає відтворенню видаленого файлу незавершеним автозбереженням.

## Межі цієї alpha

Це наближення до Live Preview Obsidian, а не повна реалізація його Markdown-рушія. Редактор залишається рядковим: виділення через кілька блоків, загальний undo, вкладені складні форматування, footnotes, backlinks, MathJax, Mermaid та справжні image/note embeds не реалізовані. Таблиці підтримують прості рядки з початковим і кінцевим |; вирівнювання колонок Markdown не застосовується. Wikilinks переходять лише до вже створених нотаток.

## Перевірки

Пройдено Node syntax check і автоматизовані перевірки продовження списків, позиції після маркера, ізоляції Boost domains, escaping, посилань, збереження без перебудови DOM, збереження файлу при pinned unload і видалення при повному закритті.

Інтерактивний тест у Zen не виконано. Після встановлення перевірте введення після паузи автозбереження, правий клік/буфер обміну, Add to Note, два різні Boosts, назву pinned note після закриття та остаточне видалення тестової нотатки. Кілька одночасно відкритих вікон Zen зі спільним index.json потребують додаткового тестування.
