# Zen Notes 0.12 alpha

Замініть ZenNotes.uc.js, ZenNotes.css і theme.json у встановленому моді Sine, потім повністю перезапустіть Zen. Автоматично у профіль цю збірку не встановлено.

## Нове у 0.12

- Glance більше не отримує фіктивний прямокутник 1×1 без clientX/clientY: посилання редактора відкриваються без знімка елемента. Тимчасові вкладки Glance не розпізнаються як нотатки.
- Нативна підказка містить лише клікабельний текст — порожню кнопку прибрано.
- Source показується маленькою іконкою сайту з кешу браузера. Клік відкриває джерело, наведення показує назву. За відсутності favicon браузер може показати стандартну іконку. Повний Source зберігається у Markdown та експорті.
- Cmd/Ctrl+Shift+A відкриває меню за координатами виділення, без прив’язки ширини до вкладки. Меню має ширину до 320 px. Якщо координати недоступні, воно відкривається компактно в центрі сторінки. Отримання виділення з віддалених iframe залежить від підтримки браузера.
- Вибрані команди в палітрі мають білий текст та іконку.
- Після SSTabRestored / SSWindowStateReady повторно відновлюються назва, іконка та редактор. SVG іконки отримує явні кольори поточної теми замість залежності від context paint у кешованому favicon.
- Конфліктні штатні key bindings Cmd/Ctrl+Shift+N/A тимчасово вимикаються, поки мод працює, щоб разом із нотаткою не відкривалося нове вікно. При вивантаженні моду попередні bindings відновлюються.

Перевірено синтаксис і регресійні тести з підставними API; реальний перезапуск Zen і Glance ще не перевірено. Уже збережене в сесії окреме порожнє вікно не закривається автоматично: закрийте його один раз вручну. Якщо воно знову створиться, причина потребує додаткової перевірки у браузері.

## Нове у 0.11

- Cmd/Ctrl+A у тілі нотатки використовує одну область виділення для всього тексту. У заголовку й полі пошуку виділення залишається локальним.
- Undo/Redo зберігає прокрутку та відновлює курсор поблизу поточної позиції замість переходу на перший рядок.
- Cmd/Ctrl+Shift+N створює нотатку. Cmd/Ctrl+Shift+A отримує виділення зі сторінки й відкриває вибір нотатки. Комбінації замінюють стандартні браузерні дії; без виділення друга команда нічого не додає.
- Під кожним новим фрагментом із сайту зберігається Source з назвою та URL сторінки. Старі фрагменти не мають автоматично відновленого джерела. Джерело зберігається як звичайне Markdown-посилання разом із фрагментом, тому його можна редагувати або видалити.
- Option/Alt+клік на HTTP(S)-посиланні в нотатці викликає нативний Zen Glance. Якщо API Glance відсутній, відкривається звичайна вкладка.
- Повідомлення про додавання використовує gZenUIManager.showToast і штатні стилі Zen; клік на повідомлення або Open note відкриває нотатку.
- Прибрано фон навколо іконки в палітрі команд.
- Link to Note вставляє посилання на наявну нотатку. Виділений текст стає підписом посилання, без виділення використовується назва. Текст не переноситься, нова нотатка не створюється. Пункт недоступний, якщо немає іншої нотатки або курсору/виділення у тілі редактора.

Перевірено синтаксис JavaScript та автоматичні тести із підставними браузерними API. Нативний Glance, анімацію повідомлення й виділення у реальному Zen потрібно перевірити після встановлення. Збірку не встановлено у профіль і не опубліковано на GitHub автоматично.

## Нове у 0.10

- Клік чекбокса зберігає вигляд задачі, не відкриває її Markdown. Скасування зміни доступне через Cmd/Ctrl+Z.
- Завершене inline-форматування залишається видимим і під час редагування всередині нього; маркери залишаються частиною джерела.
- Enter у звичайному тексті створює новий абзац (порожній Markdown-рядок між абзацами). Shift+Enter — перенесення рядка всередині абзацу. У списках Enter продовжує список, у коді — рядок коду.
- На посиланнях сайтів з’являється Add Link to Note з вибором нотатки. На зображеннях збережено додавання картинки.
- Після додавання тексту/посилання/фото з’являється повідомлення «Text/Link/Image added to note · Open note». Клік відкриває нотатку; при наведенні таймер зупиняється.
- Link to Note у меню редактора вставляє посилання на іншу нотатку за її сталим ID, тому перейменування його не ламає. Також підтримуються `[[Назва нотатки]]` і `[[Назва нотатки|Свій підпис]]`. Такі ручні посилання залежать від назви; при дублюванні назв обирається перша.
- Додано `.github/workflows/sine-update.yml` для репозиторію `preperevet-1/zen-notes`. Деталі у GITHUB-UPDATES.md.

## Нове у 0.9.1

- У редакторі вбудовані картинки мають короткий запис `![Image](zen-image:1)`. Це тимчасове позначення: при збереженні, копіюванні та експорті Markdown повертаються повні дані Base64. Розмір файла не зменшується, фото залишаються автономними.
- Правий клік не переводить прев’ю в сирий текст, тому доступне меню Hide / Show Video Preview.
- Formatting → Task List додає задачі. Синтаксис: `- [ ] Завдання`, `- [x] Виконано`. Після переходу з рядка видно чекбокс; клік перемикає стан, Enter продовжує список.
- У палітрі залишено іконку та New Note без додаткової сірої плашки. Повна команда `create note` + Enter також працює.

Перевірено синтаксис JavaScript і автоматичні перевірки логіки з підставними браузерними API. Нативне меню й кліки в Zen потребують перевірки після встановлення.

## Зміни

- Цитати використовують змішування кольорів поточного фону та accent: змінюються разом із Boost.
- Повернуто іконку документа з версії до 0.8, розмір 19 px.
- Send to Apple Notes створює звичайну нотатку зі структурованим вмістом: зберігаються базові заголовки, жирний/курсив, цитати, таблиці й посилання. Це не HTML-вкладення. Apple Notes зберігає форматований body у своєму внутрішньому HTML-форматі. Частина розширень Markdown та зовнішні зображення можуть імпортуватися інакше.
- З контекстного меню редактора прибрано Share… та Insert Image from File….
- Фото додаються перетягуванням файлів PNG/JPEG/GIF/WebP у нотатку. Дані картинки зберігаються в .md; після імпорту початковий файл не потрібний. Якщо перетягнути поза рядком, фото додається наприкінці.
- Нативний Share у меню вкладки залишається: Notes отримує форматовану нотатку, інші сервіси отримують текст із URL, без HTML-файлу. Сервіс має підтримувати текст; інакше показується помилка. Системне вікно передачі завершує користувач. Для роботи використовується автоматизація macOS; може знадобитися системний дозвіл.
- Add to Note та перемикання вкладок перевіряють фактичну наявність .md. Метадані видалених вручну файлів відкидаються; автозбереження й Add to Note не відтворюють відсутній файл. Новий файл записується перед додаванням в індекс.
- У штатну палітру команд Zen зареєстровано **New Note**, з пошуком за **New Note**. Відображення залежить від увімкнених quick actions Zen та ранжування запиту. Повні команди з Enter також працюють.

## Відео

Прев’ю підтримується **лише для YouTube** (watch, youtu.be, Shorts, Live, embed). Для інших сервісів залишається звичайне посилання.

- Назва відео отримується через YouTube oEmbed та зберігається в метаданих нотатки. Відправляється лише URL відео; запит не використовує cookies. Якщо запит не вдався, використовується підпис Markdown-посилання або «Video».
- ПКМ на картці → **Hide Video Preview** прибирає обкладинку, залишаючи компактну плашку з назвою і переходом до відео.
- **Show Video Preview** повертає обкладинку. Вибір зберігається для цього відео в цій нотатці.
- Клік відкриває відео, а не запускає вбудований плеєр.

## Перевірки

70 автоматизованих перевірок з підставними API та syntax check пройдено. Перевірено попередні можливості, очищення метаданих відсутніх файлів, палітру команд, drop, форматований body Notes, текст для інших сервісів, завантаження/збереження назви відео.

Це не інтерактивний тест у Zen. Реальні системні вікна Share, автоматизація Notes та нативний список команд потребують перевірки після встановлення. Якщо macOS відхиляє Automation, дані не будуть передані. Експериментальний редактор не є повною реалізацією Obsidian/CommonMark.
