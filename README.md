# Zen Notes 0.7.0 alpha

Замініть ZenNotes.uc.js, ZenNotes.css та theme.json у встановленому моді Sine і повністю перезапустіть Zen. Профіль браузера автоматично не змінювався.

## Зміни 0.7

- Clear Formatting відновлює початковий регістр після нових Upper/Lower/Capitalize, коли виділений текст точно збігається зі збереженим результатом зміни. Для старого суцільного UPPERCASE без записаного оригіналу застосовується lower case: первісний змішаний регістр відновити неможливо. Cmd+Z скасовує очищення.
- Add Divider у меню нотатки під Formatting вставляє Markdown-розділювач `---` із порожніми рядками.
- Іконка посунута вліво на 1 px.
- Перед Create Note… у підменю Add to Note додано сепаратор.
- Пошук знизу по центру; лише блакитне підсвічування входжень, без рамки і фону всього рядка. Потрібний CSS Highlights API, який є у сучасному Zen.
- Автопари для *, _, `, ~, =. Другий символ у порожній парі * / _ / ~ / = робить подвійну пару. Пробіл перед закривальним маркером завершує форматоване слово; `* ` на початку рядка лишається маркером списку.
- Закриті inline-фрагменти відображаються форматованими навіть під час введення далі у цьому рядку. Поки курсор усередині фрагмента, його Markdown-маркери видно. Збереження читає повний Markdown, включно з прихованими маркерами.
- Подія TabClose обробляється на document у capture-фазі. Копія нотатки в іншому вікні більше не блокує видалення. Видалення прибирає копії цієї нотатки з інших вікон.
- Для залишків попередніх версій: правий клік по вкладці → **Delete Note Permanently**. Це видаляє файл і всі відкриті копії саме цієї нотатки. Вивантаження pinned tab, як і раніше, не є видаленням. Немає масового автоматичного видалення старих файлів за назвою чи датою.

## Перенесення та експорт

Правий клік у нотатці:

- **Export Markdown…** — переносний .md.
- **Export HTML…** — HTML з форматуванням, посиланнями та таблицями.
- **Import Markdown…** — створює нову нотатку з .md в іншому профілі/браузері, де встановлено цей мод.

Це ручне перенесення файлом, не хмарна синхронізація і не публічне share-посилання. Автоматичне надсилання в акаунти не додається.

Notion підтримує імпорт Markdown/HTML: https://www.notion.com/help/import-data-into-notion
Apple Notes на Mac підтримує імпорт HTML: https://support.apple.com/en-nz/102223

Виберіть експортований файл через імпорт цільового застосунку. Доступність зовнішніх зображень залежить від джерела та підтримки імпортера; розширення на кшталт spoilers можуть переноситися як текст.

## Перевірка

Пройдено syntax check та 38 автоматизованих перевірок із підставними браузерними API: попередні можливості, регістр, автопари, inline preview, HTML, видалення копій між вікнами. Нативні діалоги імпорту/експорту, caret/IME та XUL-меню не перевірялися інтерактивно в Zen. Повної сумісності з Obsidian/CommonMark немає; це рядковий редактор з inline Live Preview.
