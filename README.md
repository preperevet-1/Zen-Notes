# Zen Notes 0.6.0 alpha

## Встановлення

Замініть **ZenNotes.uc.js**, **ZenNotes.css**, **theme.json** у каталозі встановленого мода Sine, потім повністю перезапустіть Zen. Архів сам по собі не оновлює встановлений мод. Ця збірка не встановлювалася у ваш профіль автоматично.

## Що додано

- Правий клік у тексті нотатки → **Formatting**. Без іконок, з підказками клавіш: Clear Formatting, Strikethrough, Underline, Spoiler, Monospace, Italic, Bold, Make Link, Date, Quote, Make Upper Case, Make Lower Case, Capitalize.
- **Cmd/Ctrl+A** виділяє весь текст тіла нотатки через кілька рядків, включно з Markdown-маркерами. Заголовок є окремим полем.
- **Cmd/Ctrl+Z** скасовує зміни, **Cmd/Ctrl+Shift+Z** або **Ctrl+Y** повертає їх. Історія окрема для кожної нотатки, до 200 станів, у пам'яті поточного вікна; після перезапуску історія не зберігається.
- **Cmd/Ctrl+F** відкриває Find in note: пошук у видимому тексті й заголовку, лічильник входжень, Next/Previous, Enter/Shift+Enter; Escape закриває пошук. Підсвічування точного тексту використовує CSS Highlights, якщо цей API доступний, з підсвічуванням блока як запасним варіантом.
- **Create Note** прибрано з контекстного меню конкретної вкладки; залишається у меню порожньої області сайдбара/панелі та «+».
- Іконка документа 19 px з контуром і заливкою, кольори залежать від палітри папок Zen. Скруглення сторінки й тінь використовують `--zen-native-inner-radius` та `--zen-big-shadow`.
- Прибрано подвійні рамки комірок таблиць та видимий проміжок від рядка `| --- | --- |`.
- Зображення Markdown відображаються в нотатці. Підтримуються HTTP(S)-адреси й raster data URL: PNG/JPEG/GIF/WebP.
- Зображення PNG/JPEG/GIF/WebP можна вставити з буфера. Воно зберігається всередині Markdown як data URL.
- Правий клік на HTTP(S)-зображенні сайту → **Add to Note** після другого видимого сепаратора; після пункту додано ще один сепаратор. Зображення з сайту додається за URL, а не завантажується локально. Його доступність залежить від сайту.
- Збережено виправлення 0.5.2: немає автовідкриття всього індексу; повне закриття останньої вкладки нотатки видаляє .md, а .deleted блокує повернення зі старого індексу. Вивантаження pinned tab не є видаленням.

## Клавіші Formatting

| Дія | macOS | Windows/Linux |
| --- | --- | --- |
| Bold | Cmd+B | Ctrl+B |
| Italic | Cmd+I | Ctrl+I |
| Strikethrough | Cmd+Shift+X | Ctrl+Shift+X |
| Underline | Cmd+Shift+U | Ctrl+Shift+U |
| Spoiler | Cmd+Shift+P | Ctrl+Shift+P |
| Monospace | Cmd+Shift+K або Cmd+E | Ctrl+Shift+K або Ctrl+E |
| Make Link | Cmd+U або Cmd+K | Ctrl+U або Ctrl+K |
| Quote | Cmd+Shift+I | Ctrl+Shift+I |

Underline зберігається як `<u>текст</u>`, Spoiler — як `||текст||`; це розширення базового Markdown. Клік розкриває spoiler. Make Link вставляє шаблон `[текст](https://)` — адресу потрібно дописати.

## Перевірки та межі

Пройдено перевірку синтаксису та 25 автоматизованих перевірок логіки: видалення/індекс, image URL та небезпечні схеми, форматування, undo/redo, клавіші, розташування image menu, видалення Create Note з tab menu, тема іконки. Тести використовують підставні браузерні API; це не інтерактивна перевірка у Zen. Візуальний тест і нативне XUL-меню потребують перевірки після встановлення.

Редактор лишається рядковим Live Preview, а не повною копією Obsidian чи Markdown Live Preview. Таблиці — прості pipe-таблиці з рівними колонками; Markdown-вирівнювання колонок, footnotes, MathJax, Mermaid та backlinks не додавалися. Formatting працює з тілом нотатки. Локальні файли через `file:` та тимчасові `blob:`-адреси картинок не підтримуються.
