# Zen Notes 0.14.3 alpha

## Виправлення 0.14.3

- Картинка є нередагованим елементом усередині рядка. Натискання та відпускання краю під час resize не повинні активувати Markdown-редагування; штатне перетягування картинки вимкнено.
- Службові позначки видалення перенесено в приховану папку `.deleted`. Після запуску старі файли `*.deleted` автоматично переносяться туди; вони містять час видалення, а не вміст нотаток. Захист від повторного відновлення видалених нотаток збережено.

Профіль браузера під час підготовки не змінено. Міграція виконається після встановлення та перезапуску. Інтерактивна перевірка resize в Zen ще потрібна.

## Оновлення на основі 0.14

Цю збірку підготовлено з архіву 0.14 за уточненим списком змін. Вона замінює незавершену 0.14.1. Блокове перетягування, зміст, згортання розділів і масштабування з 0.15 не включені.

- **Add Page to Note** розташовано після **Move to Folder**. Вставлення посилання не створює порожніх абзаців.
- **Add Link to Note** розташовано перед першим розділювачем; **Link to Note** у редакторі — перед розділювачем форматування. **Add Divider** перенесено у **Formatting**.
- Дата створення закріплена справа вгорі й не прокручується разом із текстом.
- Розмір зображення змінюється перетягуванням правого краю або правого нижнього кута. Видимих ручок чи панелі немає, змінюється лише курсор. Сусідні зображення стають в один ряд, якщо вистачає ширини; решта переносяться. Пропорції зберігаються, ширина записується в Markdown.
- Quick Note використовує фізичну клавішу N, захист від повторних натискань і очікування завершення закриття Glance. Підказку та кнопку збереження з чернетки прибрано. Для збереження використовуйте штатне розгортання Glance; після успішного запису з'явиться **Note saved**.
- Перейменування через штатний подвійний клік Zen синхронізує назву з файлом нотатки без відкриття її вкладки. Діють налаштування нативного перейменування Zen.
- Меню вкладки містить **Delete Note** і **Duplicate Note**. Меню редактора містить **Show in Finder** на macOS або **Show in Folder** на Windows/Linux.
- Запит **notes** у пошуку показує **Create Note** та наявні нотатки; після пробілу можна фільтрувати за назвою.
- PDF має SVG-іконку документа, без підкреслення. Перевірку орфографії в нотатках вимкнено.
- Історія змін записується синхронно для Undo/Redo. Під час перетягування виділення тексту редактор об'єднує абзаци в одну область; у цьому режимі видно Markdown.
- Нативна статична назва вкладки та відновлення метаданих допомагають зберігати назву нотатки замість **New Tab**.

Перевірено синтаксис, 26 базових перевірок 0.14, 7 перевірок нової логіки та 3 перевірки меню/PDF із підставними браузерними API. Нативні API зіставлено з файлами встановленого Zen. Інтерактивно перетягування мишею, розкладку зображень, анімації Glance та Windows/Linux не перевірено. Це alpha-збірка; профіль браузера автоматично не змінювався.

Для встановлення замініть **ZenNotes.uc.js**, **ZenNotes.css** і **theme.json** у моді Sine та повністю перезапустіть Zen. Нижче збережено історію попередніх версій; опис 0.14.2 має пріоритет.

## Нове у 0.14

- PDF-посилання з адресою, що закінчується на `.pdf` (перед параметрами URL), показується компактною карткою з іконкою та назвою файла. Локальний PDF можна перетягнути або вставити з буфера, якщо ОС передає файл. Копія PDF зберігається всередині Markdown; редактор показує короткий псевдонім. При відкритті створюється тимчасова копія для PDF-переглядача браузера.
- Неактивна нотатка у Split View має ту саму типографіку та параметри Boost, що й активна.
- ПКМ на звичайній вебвкладці → **Add Page to Note** → наявна або нова нотатка. Додається посилання саме на вибрану вкладку, навіть якщо вона неактивна.
- Меню вкладки нотатки залишає перейменування, закріплення, експорт, видалення та доступні нативні дії папок і Split View. Меню звичайних вкладок відновлюється без цих обмежень.
- **Quick Note**: macOS `⌘⌥⇧N`; Windows/Linux `Ctrl+Alt+Shift+N`. Відкриває чернетку в нативному Glance. Кнопка розгортання Glance або **Save as Note** зберігає її як звичайну нотатку. Закриття прев’ю відкидає чернетку. Поки інше Glance відкрите, нова чернетка не створюється.
- Колір елементів за замовчуванням — блакитний; увімкнений кольоровий Boost має пріоритет.
- Виділення тексту → ПКМ → **Text Color** або **Background Color**: Purple, Pink, Orange, Mint, Blue та Default. Текст і фон можна змінювати незалежно. Кольори записуються стандартними HTML-span у Markdown та зберігаються в HTML-експорті.
- Унизу нотатки показується дата й час створення сірим текстом у форматі системної локалі.
- Windows/Linux використовують Ctrl у комбінаціях та підписах меню. Apple Notes доступний лише на macOS; експорт Markdown/HTML доступний на всіх платформах.

Перевірено синтаксис JavaScript, 26 логічних перевірок PDF, кольорів і життєвого циклу чернетки та три варіанти платформної комбінації. Перевірки використовують підставні браузерні API. Нативний інтерфейс Zen, Glance та встановлення на Windows/Linux у цій сесії не перевірялися. Профіль браузера не змінено, збірка не опублікована на GitHub.


Замініть ZenNotes.uc.js, ZenNotes.css і theme.json у встановленому моді Sine, потім повністю перезапустіть Zen. Автоматично у профіль цю збірку не встановлено.

## Нове у 0.13

- Редактор прив’язаний до browserStack своєї вкладки, а не до загального tabbox. Нотатка лишається у власній панелі Split View; клік по неактивній панелі активує її редактор. Інші відкриті нотатки показуються як попередній перегляд до активації.
- При переході до Glance та назад відображення нотатки зберігається у її панелі, щоб не оголювати базову about:home. Високий глобальний z-index замінено локальним.
- Source додається в кінець вставленого тексту як маленька клікабельна іконка. Старі окремі рядки Source під час відкриття об’єднуються з попереднім текстом. Markdown і HTML-експорт зберігають URL джерела.
- Виявлено причину зайвого вікна: збережений popup із вкладками вже видалених нотаток. Після запуску звичайного вікна мод перевіряє popup-вікна, які містять **лише** вкладки нотаток. Якщо файл є — переносить вкладку до звичайного вікна; якщо файла немає — прибирає застарілу вкладку. Порожній popup закривається. Змішані вікна з іншими сторінками не обробляються. Файли нотаток цим очищенням не видаляються.

Перевірено синтаксис JavaScript та регресійні тести із підставними API (зокрема захист звичайних popup-вікон та збереження наявних нотаток). Реальне відкриття Split View/Glance і перезапуск Zen ще потрібно перевірити після встановлення. Профіль браузера не змінювався під час підготовки цієї збірки.

## Нове у 0.12

- Glance більше не отримує фіктивний прямокутник 1×1 без clientX/clientY: посилання редактора відкриваються без знімка елемента. Тимчасові вкладки Glance не розпізнаються як нотатки.
- Нативна підказка містить лише клікабельний текст — порожню кнопку прибрано.
- Source показується маленькою іконкою сайту з кешу браузера. Клік відкриває джерело, наведення показує назву. За відсутності favicon браузер може показати стандартну іконку. Повний Source зберігається у Markdown та експорті.
- Cmd/Ctrl+Shift+A відкриває меню за координатами виділення, без прив’язки ширини до вкладки. Меню має ширину до 320 px. Якщо координати недоступні, воно відкривається компактно в центрі сторінки. Отримання виділення з віддалених iframe залежить від підтримки браузера.
- Вибрані команди в палітрі мають білий текст та іконку.
- Після SSTabRestored / SSWindowStateReady повторно відновлюються назва, іконка та редактор. SVG іконки отримує явні кольори поточної теми замість залежності від context paint у кешованому favicon.
- Конфліктні штатні key bindings Cmd/Ctrl+Shift+N/A тимчасово вимикаються, поки мод працює, щоб разом із нотаткою не відкривалося нове вікно. При вивантаженні моду попередні bindings відновлюються.

Перевірено синтаксис і регресійні тести з підставними API; реальний перезапуск Zen і Glance ще не перевірено. Уже збережене в сесії окреме порожнє вікно не закривається автоматично: закрийте його один раз вручну. Якщо воно знову створиться, причина потребує додаткової перевірки у браузері.

## Зміни

- Цитати використовують змішування кольорів поточного фону та accent: змінюються разом із Boost.
- Повернуто іконку документа з версії до 0.8, розмір 19 px.
- Send to Apple Notes створює звичайну нотатку зі структурованим вмістом: зберігаються базові заголовки, жирний/курсив, цитати, таблиці й посилання. Це не HTML-вкладення. Apple Notes зберігає форматований body у своєму внутрішньому HTML-форматі. Частина розширень Markdown та зовнішні зображення можуть імпортуватися інакше.
- З контекстного меню редактора прибрано Share… та Insert Image from File….
- Фото додаються перетягуванням файлів PNG/JPEG/GIF/WebP у нотатку. Дані картинки зберігаються в .md; після імпорту початковий файл не потрібний. Якщо перетягнути поза рядком, фото додається наприкінці.
- Нативний Share у меню вкладки залишається: Notes отримує форматовану нотатку, інші сервіси отримують текст із URL, без HTML-файлу. Сервіс має підтримувати текст; інакше показується помилка. Системне вікно передачі завершує користувач. Для роботи використовується автоматизація macOS; може знадобитися системний дозвіл.
- Add to Note та перемикання вкладок перевіряють фактичну наявність .md. Метадані видалених вручну файлів відкидаються; автозбереження й Add to Note не відтворюють відсутній файл. Новий файл записується перед додаванням в індекс.
- У штатну палітру команд Zen зареєстровано **New Note**, з пошуком за **New Note**. Відображення залежить від увімкнених quick actions Zen та ранжування запиту. Повні команди з Enter також працюють.

## Відео

Прев’ю підтримується **лише для YouTube** (watch, youtu.be, Shorts, Live, embed). Для інших сервісів залишається звичайне посилання.

- Назва відео отримується через YouTube oEmbed та зберігається в метаданих нотатки. Відправляється лише URL відео; запит не використовує cookies. Якщо запит не вдався, використовується підпис Markdown-посилання або «Video».
- ПКМ на картці → **Hide Video Preview** прибирає обкладинку, залишаючи компактну плашку з назвою і переходом до відео.
- **Show Video Preview** повертає обкладинку. Вибір зберігається для цього відео в цій нотатці.
- Клік відкриває відео, а не запускає вбудований плеєр.

## Перевірки

70 автоматизованих перевірок з підставними API та syntax check пройдено. Перевірено попередні можливості, очищення метаданих відсутніх файлів, палітру команд, drop, форматований body Notes, текст для інших сервісів, завантаження/збереження назви відео.

Це не інтерактивний тест у Zen. Реальні системні вікна Share, автоматизація Notes та нативний список команд потребують перевірки після встановлення. Якщо macOS відхиляє Automation, дані не будуть передані. Експериментальний редактор не є повною реалізацією Obsidian/CommonMark.
