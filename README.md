# Zen Notes 0.8.0 alpha

## Встановлення

Замініть ZenNotes.uc.js, ZenNotes.css та theme.json у встановленій копії Sine і повністю перезапустіть Zen. Цю збірку автоматично у профіль не встановлено.

## Нове

- **YouTube preview:** URL відео окремим рядком, або `[назва](URL)`, відображається карткою з обкладинкою. Підтримуються youtube.com/watch, Shorts, Live, embed та youtu.be. Клік відкриває відео; плеєр усередині нотатки не вбудовується. Обкладинка завантажується з i.ytimg.com. Для інших відеосервісів зберігається звичайне посилання.
- **Цитати:** суміжні рядки `>` мають спільну блакитну плашку зі скругленнями, з темним варіантом для темної теми.
- **Apple Notes текстом:** ПКМ у нотатці → Send Text to Apple Notes. Також сервіс Notes у меню Share використовує цю дію. Мод створює нову нотатку через системну автоматизацію Notes і відкриває її, без HTML-файлу-вкладення. Сам вміст передається як екранований текст; URL залишаються в тексті. Зображення замінюються підписами/адресами, оскільки це текстове перенесення.
- macOS може попросити дозвіл Zen на керування Notes. Команда працює лише після натискання пункту меню. Нічого автоматично не надсилається. Зберігання нової нотатки (локально/iCloud) визначається налаштуваннями Notes.
- **Створення:** вкладка створюється у фоні, отримує ID/іконку/назву нотатки, після чого вибирається. Прибрано конкурентне перемикання сторінки під час створення, яке могло показувати New Tab до повторного відкриття.
- **Фото з файлів:** ПКМ → Insert Image from File… → PNG, JPEG, GIF або WebP. Зображення вбудовується в .md як data URL, тому оригінальний файл не потрібен для подальшого відкриття нотатки.
- **Адресний рядок:** введіть точно `new note` або `create note` та натисніть Enter. Регістр не має значення; фрази довші за ці команди залишаються звичайним пошуком.
- **Іконка:** спрощена двошарова форма з округлими кутами, контуром і заливкою з палітри папок Zen, розмір 20 px.

Попередні можливості: Formatting, Divider, Cmd/Ctrl+A, Undo/Redo, Find, імпорт/експорт Markdown/HTML, Add to Note для виділення/картинок, окремі Boosts, видалення файлу при повному закритті останньої локальної вкладки нотатки. Вивантаження pinned tab не є видаленням. Для старих залишків доступне Delete Note Permanently.

## Перевірки

Пройдено syntax check та 62 автоматизовані перевірки з підставними браузерними API: попередні можливості, YouTube URL/підміна домену, формати зображень, текст для Notes, безпечне передавання аргументів автоматизації, порядок позначення/вибору вкладки, команди адресного рядка.

Інтерактивна перевірка у Zen та реальний виклик Apple Notes не виконувалися. Для Notes особливо перевірте системний дозвіл Automation; самі 62 тести не підтверджують інтеграцію macOS. Редактор залишається експериментальним рядковим Live Preview, а не повною копією Obsidian/CommonMark.
